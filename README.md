🎵 Spotify Landing Page Clone

A modern and responsive Spotify Landing Page Clone built using HTML5 and CSS3. This project recreates the look and feel of Spotify's homepage while focusing on clean design, responsive layouts, and an engaging user experience.

🚀 Live Demo

🔗 Visit Website: https://md-raquib-hussain90.github.io/Spotify-Clone/

📌 Project Overview

This project is a frontend clone of Spotify's landing page, created to strengthen my skills in HTML, CSS, responsive web design, and UI development. The layout is designed to closely resemble Spotify's official interface while maintaining clean and organized code.

✨ Features

- Responsive design for Desktop, Tablet, and Mobile devices
- Modern Spotify-inspired user interface
- Interactive navigation bar
- Hero section with call-to-action elements
- Music and playlist showcase cards
- Hover effects and smooth transitions
- Well-structured page layout
- Footer with navigation links
- Clean and maintainable code structure

🛠️ Technologies Used

- HTML5
- CSS3
